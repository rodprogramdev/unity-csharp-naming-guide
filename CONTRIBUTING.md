
# Contributing

Contributions that help beginners learn Unity C# naming
conventions are welcome.

## Guidelines

1. Keep explanations clear and beginner-friendly.
2. Use consistent names in code examples.
3. Distinguish C# language rules from optional style choices.
4. Test Unity Editor scripts where practical.
5. Explain the purpose of new examples and exercises.

## Pull Request Checklist

- [ ] The change has a clear purpose.
- [ ] Code examples use consistent naming.
- [ ] Documentation is updated when necessary.
- [ ] Changes have been tested where practical.
